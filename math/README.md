## 🎯 Learning Path

### **Foundation (Weeks 1-2)**
- Elementary Math (addition, subtraction, multiplication, division)
- Fractions (all operations)
- Ratios & Proportions

**Goal:** Build computational fluency

### **Intermediate (Weeks 3-4)**
- Pre-Algebra (variables, simple equations)
- Algebra (linear equations, quadratics, polynomials)
- Geometry (area, volume, angles)

**Goal:** Master algebraic thinking

### **Advanced (Weeks 5-6)**
- Trigonometry (functions, identities, solving triangles)
- Pre-Calculus (functions, logs, exponentials)

**Goal:** Prepare for calculus

### **Calculus & Beyond (Weeks 7-10)**
- Calculus (limits, derivatives, integrals)
- Differential Equations
- Algebraic Geometry

**Goal:** Advanced mathematical reasoning

## 💡 Study Strategies

### **For Skill Building:**
1. **Repetition** - Do similar problems multiple times
2. **Timed practice** - Build speed with accuracy
3. **No calculator** - Strengthen mental math
4. **Show all work** - Develop systematic approach

### **For Conceptual Understanding:**
1. **Explain out loud** - Teach the concept to yourself
2. **Draw diagrams** - Visualize problems
3. **Find patterns** - Look for connections
4. **Ask "why"** - Understand the reasoning

### **When Stuck:**
1. Review related problems you've solved
2. Break problem into smaller steps
3. Check solution for hints (don't just copy!)
4. Try a similar but simpler problem first
